## 실행한 프롬프트

```
1. 점선으로 이어져있는게 아니라 클러스터가 사라지고 자연스럽게 나오도록 해줘
2. 확대를 조금 많이했을떄 나오도록해줘
3. 클릭시에는 줌확대를하고 1번사항처럼 나오도록 해줘
```

## 작업 내용

| 요청 | 파일 | 조치 |
|---|---|---|
| ① 연결선 없이 자연스럽게 | `js/modules/map/map-facility.js` | 점선 연결선(`__spiderLine`) 생성·스타일·히트테스트 **전부 제거**. 펼친 묶음은 **개수 배지를 숨김**(`isFacilitySpiderExpandedGroup()` → 배지 스타일 `null`), 묶어 보기를 껐을 때는 **원래 자리의 핀을 숨김**(`facilityStyleFunction`이 `isFacilitySpiderExpanded()`로 판단) → 화면에는 흩어진 핀만 남는다 |
| ② 더 확대했을 때 | 〃 | 기준 배율 `FACILITY_SPIDER_MIN_ZOOM` **16 → 18**(최대 배율 19). 펼침 반지름도 46px → 42px |
| ③ 클릭 시 확대 후 동일 동작 | 〃 | 묶음 배지 클릭은 `max(현재+2, 18)` 배율까지 확대만 하고, 그 결과로 동기화가 흩뿌린다 |
| 스타일 분리 | 〃 | `buildFacilityPinStyle()`(펼침 여부를 보지 않는 핀 스타일)을 분리해 펼친 핀이 "펼쳐진 것은 숨김" 규칙에 걸려 사라지지 않게 함 |
| 다시 그리기 | 〃 | 펼침 대상이 바뀌면 본 레이어도 `changed()` — 원래 자리의 핀·배지를 숨기거나 되살리기 위함 |
| 문서 | `docs/map-architecture.md`, `docs/ui-conventions.md` | 연결선 없음·배지 숨김·기준 배율 18·클릭 동작으로 갱신 |

## 검증 (로컬, 헤드리스 Chrome + CDP)

같은 자리 묶음(3건)이 있는 지점에서 배율만 바꿔 관찰했습니다.

| 배율 | 펼친 핀 |
|---|---|
| 16 | 0 |
| 17 | 0 |
| **18** | **3** |
| 19 | 3 |
| 14 (축소) | 0 |

| 그 밖의 확인 | 결과 |
|---|---|
| 펼친 묶음의 개수 배지 | 스타일 `null` = **숨김** |
| 펼친 핀 3개 | 모두 스타일 있음(그려짐) |
| 연결선 | 소스에 선 피처 없음(핀 3개만) |
| 배율 14에서 묶음 클릭 | 줌 14 → **18**, 펼친 핀 0 → **3** |
| 화면 캡처 | 배지 없이 핀 3개만 흩어져 표시 |
| `node --check` | 통과 |
