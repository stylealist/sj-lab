설계 결정

왜 이렇게 만들었나

  • 레이어 우선순위 zIndex 1010 — 기존 WFS·WMS 레이어(1000) 위에 표시해 시설물이 가려지지 않게 함
  • declutter: false — 목록 건수와 지도 표출 건수를 일치시키기 위해 라벨 겹침 제거 기능을 끔
  • AbortController + 요청 순번 — 행정구역을 빠르게 바꿀 때 이전 응답이 나중에 도착해 화면을 덮어쓰는 문제 차단. 취소로 생긴 AbortError는 오류 UI를 띄우지 않음
  • 이벤트 ID 분리 — 클릭 facility-click-layer, 호버 facility-pointer-move로 기존 wfs-general-click과 분리하고, 피처를 벗어나면 커서를 즉시 복원
  • 공간 쿼리 — LEFT JOIN LATERAL + ST_Intersects(LIMIT 1)로 g_emd의 GIST 인덱스를 태우고, 행정구역은 emd_cd LIKE code || '%' 접두어 한 조건으로 필터
  • extent 변환 최소화 — 폴리곤 전체가 아니라 ST_Transform(ST_Envelope(geom), 3857)로 BBOX만 변환
  • 대량 렌더링 — 2,474건을 DocumentFragment로 한 번에 삽입, XSS 방지를 위해 textContent 사용

팝업 헤더가 화면 위로 잘리던 문제

팝업은 시설물 위쪽으로 그려지는데, 화면 위쪽 시설물을 선택하면 헤더(아이콘·제목·배지)가 잘려 보이지 않았습니다. 검증 중에 발견했습니다.

  • 오버레이에 autoPan(여백 20px, 250ms)을 켬
  • 그것만으로는 부족 — 처음 위치를 잡는 시점에는 "불러오는 중" 상태라 팝업 높이가 작아, autoPan이 실제 높이를 모른 채 계산함
  • 상세 내용을 그린 뒤 setPosition(coordinate)을 한 번 더 호출해 확정된 높이로 다시 계산하도록 함

설계

왜 리다이렉트 + URL 해시인가

1 · 게이트hub/mapservice 접속 시 localStorage에 유효한 토큰 없으면 /auth/login.html?redirect_uri=...로 즉시 리다이렉트
2 · 로그인로그인 페이지가 자기 오리진의 세션 쿠키를 GET /auth/session으로 먼저 확인 — 있으면 폼 없이 새 토큰 발급, 없으면 폼 → POST /auth/login
3 · 복귀redirect_uri#auth_token=...로 되돌아가며 URL 해시에 토큰 전달
4 · 저장원래 사이트의 게이트 스크립트가 해시에서 토큰을 꺼내 자기 localStorage에 저장, 해시는 지움

hub(3000)·mapservice(4000)·authserver(8100)는 로컬에서 서로 다른 오리진이라 쿠키를 직접 공유할 수 없습니다. 로그인 페이지 자신의 세션 쿠키는 같은 오리진으로의 최상위 탐색에서만 쓰이므로 SameSite=Lax로 충분하고, SameSite=None+Secure가 요구하는 HTTPS 제약(로컬 http에서 못 씀) 없이 동작합니다.

겪은 문제

Spring Security 기본 로그아웃 필터와 충돌

SecurityConfig에서 authorizeHttpRequests(...).permitAll()만 해뒀더니, POST /logout 요청이 우리 AuthController#logout()에 도달하기 전에 Spring Security가 자동 등록한 로그아웃 필터가 먼저 가로채 /login?logout으로 302 리다이렉트했습니다. 클라이언트 쪽에서는(리다이렉트를 따라간 GET이 POST 전용 /login에 걸려) 405로 보여 원인을 한 번에 알기 어려웠습니다.

수정: .logout(AbstractHttpConfigurer::disable) 명시적으로 추가

설계

아이콘을 다시 만들지 않았다

  • 지도에 쓰는 함수를 그대로 씬다 — 시설물은 buildFacilityIconUrl()·buildFacilityClusterIconUrl(), WFS 는 스타일의 ol.style.Icon#getSrc()

  • 각 레이어 모듈은 목록 함수 하나씩만 내준다 — getFacilityLegendItems() · getWfsLegendItems() · getWmsLegendItems()
