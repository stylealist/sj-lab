## 1. 네 저장소를 올렸습니다

이틀치 작업(v4.16 ~ v4.19)이 로컬에만 있었습니다. 저장소별로 나눠 커밋하고 올렸습니다.

| 저장소 | 내용 |
|---|---|
| `sj-lab-estate` | 지도 경계·아파트 핀 조회 API |
| `sj-lab-estate-web` | 본문 전체 지도 + 단지 월별 시세 팝업 |
| `sj-lab-scheduler` | 단지 좌표 수집 배치 |
| `sj-lab` | 기록 4개 · 좌표 표 스크립트 · 절차 문서 |

올리면 **운영 배포가 자동으로 시작됩니다**(화면은 파일 복사, 서버는 이미지 → 배포).
scheduler 의 좌표 수집은 **키가 없으면 아무것도 하지 않으므로** 올려도 조용합니다.

## 2. 아파트 핀 — 코드는 끝났고, 사람이 할 일이 둘 남았습니다

"핀을 만들어 달라"는 요청에 대해 **코드로 할 수 있는 것은 이미 다 되어 있습니다.** 다시 확인했습니다.

| 확인한 것 | 결과 |
|---|---|
| 좌표를 담을 표 | 아직 없음(`estate.apt_complex`) |
| 표를 채우는 배치 | 있음 (단지 긁어오기 · 좌표 받기 · 진행률) |
| 좌표를 지도로 올리는 API | 있음 |
| 핀 + 가격 라벨 + 팝업 | 있음 |
| **표의 컬럼 이름과 양쪽 코드가 맞는지** | **전부 일치**(이게 어긋나면 표를 만든 뒤에 터집니다) |

그래서 사람이 해야 하는 것은 **두 가지**입니다.

1. **좌표 표 만들기** — `db/estate/estate_apt_complex.sql` 을 DB 에서 한 번 실행
2. **주소 좌표 API 키 받기** — 행안부 주소기반산업지원서비스에서 신청(무료)

이 둘이 들어오면 나머지(단지 4.5만 개 긁어오기 → 좌표 채우기)는 이어서 진행합니다.

## 3. 키는 기다릴 필요가 없다는 것을 확인했습니다

| 길 | 상태 |
|---|---|
| **좌표 API 승인키** | **심사 없이 신청 즉시 발급** ← 이 길로 갑니다 |
| 좌표가 담긴 파일 DB | 이용목적 **심사 10일** 필요(도로명주소법 시행령) |

처음엔 "키 신청 → 승인 대기"를 걱정했는데, 즉시 발급이라 **받는 날 바로 수집을 시작**할 수 있습니다.
(좌표가 담긴 파일을 내려받는 길도 있지만 심사를 받아야 해서 쓰지 않습니다.)
