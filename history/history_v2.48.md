## 실행한 프롬프트

```
1. 풀동영상 qgis 초반부분의 화면과 자막의 sync가 안맞음
   - qgis에서 qfieldcloud 로그인 ~ vworld 배경지도까지의 sync가 안맞음
2. 현장조사 앱(Qfield 포크)에서 조사 프로젝트를 엽니다. → '(Qfield 포크)' 부분 제거
3. 동기화된 데이터는 30초 주기 워커가 PostGIS로 적재합니다.
   → '30초 주기' 정확한 시간을 쓰지 말고 '주기적으로' (소개·연락처탭 등 영상이 아닌 부분도)
4. 영상에서 (사무실처리) 제거
5. '그 자리의 거리 모습을 로드뷰로 확인합니다' → '선택한 장소의 로드뷰를 확인합니다'
```

### 동기화 주기 표현 — 화면에서도 모두 교체

"정확한 시간을 쓰지 말라"는 요청에 따라 **사이트 문구 7곳**을 함께 고쳤습니다.

| 위치 | 전 → 후 |
|---|---|
| 소개 탭 지표 카드 | `30초` → **`주기적`**, "앱에서 올린 내용을 30초마다 확인해 받아옵니다" → "주기적으로 확인해 받아옵니다" |
| 소개 탭 파이프라인 ② | "30초마다 받아오기" → "주기적으로 받아오기", 설명의 "30초마다" → "주기적으로" |
| 저장소·문의 탭 안내 | "보통 30초 안에 지도에 나타납니다" → "주기적으로 동기화되어 잠시 뒤 지도에 나타납니다" |
| 인트로 팝업 설명 | "30초 안에 지도에 올라오고" → "주기적으로 동기화되어 지도에 올라오고" |
| 팝업 폴백 카드 | "30초마다 동기화 → …", 태그 `#30초마다 동기화` → "주기적으로 동기화", `#주기적 동기화` |
| `README.md` | "현장 외업 → 30초 동기화 → PostGIS → 웹 관제" → "주기적 동기화" |

실제 주기(30초)는 **개발 문서에만** 남겨 두었습니다(`docs/map-architecture.md`, 허브 저장소 `docs/system-architecture.md`) — 운영 중 주기가 바뀌어도 화면 문구가 거짓이 되지 않도록.
