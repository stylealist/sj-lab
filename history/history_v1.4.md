## 문제

시설물 레이어가 편의시설(상점) 아이콘인 `images/icon/amenities_icon.png`를 그대로 쓰고 있어, 지도에서 시설물이 상점처럼 보였습니다. 실제 데이터는 기관 내 시설이라 의미가 맞지 않았습니다.

DB 조회로 확인한 시설물 구성(상위): 주차장 42, 강당 14, 카페 10, 구내식당 10, 전기차 충전소 8, 소형강의실 8, 테니스장·농구장 등 체육시설, 회의실, 전시시설. 총 2,474건 중 `repair_required_yn = 'Y'`는 1건입니다.

| 종류 | 판별 키워드 | 글리프 |
|---|---|---|
| 주차장 | 주차 | P |

| 강당·강의실·회의실 | 강당, 강의, 회의, 세미나, 교육, 대회의 | 스크린 + 받침 |

- 핀 기본색 `#2563eb`(파랑), `repair_required_yn === 'Y'`이면 `#d97706`(주황)으로 바꿔 보수 필요 시설을 한눈에 구분합니다.
- 선택된 시설물은 기존과 같이 강조 링을 그리고 아이콘을 1.25배로 키웁니다.

### 설계 결정

- **이미지 파일을 새로 추가하지 않고 SVG data URI**로 그립니다. 확대해도 선명하고, 색만 바꿔 재사용할 수 있으며, 저장소에 바이너리가 늘지 않습니다.
- **스타일 캐시(`facilityStyleCache`)** — 종류·색·선택 상태 조합으로 캐시해, 피처 2,474건을 그릴 때 `ol.style.Style`을 반복 생성하지 않습니다.
- **글리프 안의 `COLOR` 문자열**을 핀 색으로 치환하는 방식이라, 새 종류를 추가할 때 색을 직접 적지 않아도 됩니다.
- 종류 추가는 `FACILITY_ICON_TYPES` 배열에 `{ type, keywords, glyph }` 한 줄을 넣으면 됩니다.

## 검증 결과

- 로컬 스택(Eureka·mapservice-rest·게이트웨이·프론트)을 띄우고 Chrome에서 `http://localhost:4000` 확인.
- 시설물 2,474건 렌더링, **콘솔 오류 없음**.
- 스타일 함수가 돌려준 아이콘을 집계해 주차장 741건이 P 아이콘으로 분류되는 것을 확인(나머지 1,733건은 다른 종류·기본 아이콘).
- 지도 화면에서 P·스크린·공·번개·컵·건물 아이콘이 종류별로 표시되는 것을 눈으로 확인.
