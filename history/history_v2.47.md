## 1. 전체화면에서 자막이 잘리던 문제

**원인**: `css/components/intro-modal.css`의 `.intro-video-wrapper video`가 **`object-fit: cover`** 였습니다. 팝업 안에서는 래퍼가 16:9라 문제가 없지만, **전체화면에서는 창 비율(예: 16:10 노트북)이 영상과 달라 위아래가 잘려** 화면에 새겨 둔(번인) 자막이 사라졌습니다.

**수정**: `object-fit: contain` + `:fullscreen` 전용 규칙 추가(브라우저 기본 스타일 대비). 팝업 안 모양은 그대로이고, 전체화면에서는 위아래에 검은 여백이 생기는 대신 자막까지 모두 보입니다. 참조 버전 `intro-modal.css?v=20260929`.

**검증**(헤드리스 Chrome, **1440×900 = 16:10** 창에서 실제 `requestFullscreen`)

| 확인 | 결과 |
|---|---|
| 팝업 안 | `object-fit: contain`, 713×401 |
| 요약본 전체화면 | 1440×900 차지, 표시 비율 1.600 vs 영상 1.778 → **잘림 없이 레터박스**, 자막 보임(스크린샷 확인) |
| 전체본 전체화면 | 같은 결과(370.3초 영상) |
| 콘솔 오류 | 없음 |
