## 1. 확대·축소 단추 정렬

오른쪽 여백이 **확대 단추는 0.7em, 출처(ⓘ) 단추는 0.5em** 으로 서로 달라 위아래가 어긋나 있었습니다.
두 값을 CSS 변수 하나(`--ol-right`)로 묶어 맞추고, 확대 단추를 **한 칸 위로** 올렸습니다.

## 2. 화면 전체를 헤더 톤으로

종전에는 **헤더만 어둡고 그 아래가 전부 흰색**이었습니다. 대비가 너무 세서 조건·관심 담기·메모
같은 작은 단추들이 하나하나 눈에 튀었습니다(사용자 지적).

이제 **헤더와 같은 딥 네이비**로 이어집니다.

| | 바뀐 것 |
|---|---|
| 지도 위 | 검색창 · 조건 거르개 · 단계 배지 · 핀 설명 · 확대 단추 |
| 왼쪽 패널 | 패널 바탕 · 머리말 · 탭 · 지역 선택 · 단지 목록 · 표 · 그래프 |
| 내 단지 | 관심 · 최근 · 메모 · 내 정보 · 비교 창 |
| 그 밖 | 소개 · 문의 · 준비 중 화면, 바깥 바탕 |

**색을 한곳에 모았습니다**(`src/theme.js`). 종전에는 흰 카드 색을 파일마다 직접 적어 두어, 색 하나를
바꾸려면 파일 열 개를 고쳐야 했습니다. 이제 그 파일만 고치면 화면 전체가 함께 바뀝니다.

**지도와 단지 말풍선은 그대로 둡니다.** 배경 지도가 밝아 말풍선은 흰 바탕이 가장 잘 읽힙니다 —
어둡게 하면 지도 위에서 글자가 묻힙니다. 어둡게 한 것은 **화면의 틀**입니다.

작은 단추들은 **평소에 조용하게** 두고, 켜졌을 때만 색이 생기도록 했습니다(관심 담기는 담은 뒤에만
노란 톤, 조건은 걸었을 때만 파란 글자).

## 3. 회원 기능 — 실제로 돌려 확인했습니다

DB 스크립트를 실행해 주셔서 v4.31 에서 "확인 전" 으로 남겼던 것을 모두 확인했습니다.

| 확인 | 결과 |
|---|---|
| 회원 표 준비 상태 | `READY` |
| 관심 담기 · 같은 단지 두 번 | 정상 (두 번 눌러도 안전) |
| "새 거래" 기준일 | 담은 시점의 최근 계약일로 들어감 → 담자마자 0건 (의도대로) |
| 메모 저장 → 다시 읽기 | 정상, **한글도 정상** |
| 빈 메모로 저장 | 지워짐 |
| 최근 본 단지 | 쌓이고, 다시 보면 시각만 갱신 |
| 관심에서 빼기 · 기록 지우기 | 정상 |
| 로그인 없이 호출 | `401 로그인이 필요합니다` |

## 4. 그 과정에서 찾아 고친 것 두 가지

**① 조회 전용 계정으로는 담기가 안 됐습니다.** 로컬이 `mcp_readonly`(조회 전용)로 붙어 있어
`cannot execute INSERT in a read-only transaction` 이 났습니다. 그런 계정에는 보통 "모든 작업을
읽기 전용으로" 라는 기본값이 걸려 있고, **코드에서 쓰기 가능으로 바꿔도 계정 기본값이 이깁니다.**
그래서 회원용 연결에만 "이 연결은 쓴다" 를 명시했습니다(실거래 연결은 종전대로 읽기 전용).
로컬 접속 계정도 운영과 같은 것으로 맞췄습니다.

**② 본문을 잘못 보내면 502 였습니다.** 보낸 쪽 잘못인데 "서버가 조회에 실패했다"로 보여 원인을
찾기 어렵습니다 — 지난주 같은 종류의 문제를 한 번 고쳤고(필수 값 누락), 이번에 본문 쪽도
**400**(`INVALID_BODY`)으로 바꿨습니다.

## 5. 보시면서 바로 고친 것들 (같은 날 후속)

화면을 띄워 보시고 지적해 주신 것들입니다.

| 지적 | 고친 내용 |
|---|---|
| "핀이 너무 흰색 계열" | 말풍선도 같은 톤으로. 단 **패널보다 한 단 밝게**(`#24406f`) — 30px 짜리는 큰 면과 같은 색이면 "검은 점" 으로 보입니다 |
| "살짝 너무 어두운데 헤더 오른쪽 색으로" | 기준색을 헤더 **왼쪽(`#0b1424`) → 오른쪽(`#1b3159`)** 으로. 선·면도 함께 올렸습니다 |
| "핀은 안 바뀐 것 같아" | 적용은 됐지만 변화 폭이 작은 말풍선에서 거의 안 보였습니다 — 한 단 더 밝혔습니다 |
| "잘 안 보이는 텍스트" | 옅은 글자 투명도 `0.56 → 0.7`. 드롭다운 목록도 혼자 어두워 톤을 올렸습니다 |
| "검색바와 조건 버튼 height가 달라" | 둘 다 **명시된 높이가 없어** 각자 여백으로 정해졌습니다 → 공통 `rowHeight`(2.3rem)를 받게 |
| "스크롤 UI도 맞춰 줘" | 가로·세로 스크롤바를 톤에 맞췄습니다(막대 반투명·길 투명·모서리 투명) |
| "영역 배지 텍스트가 안 보여" | **같은 원인으로 안 보이던 곳이 두 개 더** 있었습니다(아래) |

**색 세 군데는 사실상 안 보이는 상태였습니다.** 밝은 바탕에서 쓰던 진한 색이 그대로 남아 있었습니다.

| 위치 | 전 → 후 | 대비 |
|---|---|---|
| 단지 영역 배지 | 진한 주황 → 밝은 주황 | **1.37 → 5.95** |
| 그래프 매매 선 | 진한 남색 → 밝은 파랑 | **1.24 → 5.76** |
| 그래프 전월세 선 | 진한 녹색 → 청록 | **2.35 → 8.71** |

(본문 기준은 4.5 : 1 입니다. 1.2~2.4 는 글자가 배경과 거의 같은 색이라는 뜻이고, 그래프 두 개는
**선이 안 보여 추세를 읽을 수 없는** 상태였습니다.)

**대비는 눈으로 가늠하지 않고 계산해서 확인했습니다.** 지금 모든 글자·면 조합이 4.5 : 1 이상입니다.
하드코딩으로 남은 색을 찾는 명령도 `CLAUDE.md` 에 적어 두었습니다.
