### 1. 헤더

- 텍스트만 있던 로고를 **심볼 배지(건물 아이콘) + 서비스명 + `FACILITY MANAGEMENT` 캡션** 조합으로 교체
- 배경을 회색 그라데이션에서 **딥 네이비**로 바꿔 지도 핀 파랑(`#2563eb`)과 톤을 맞춤
- 탭(지도·소개·연락처)은 알약형 컨테이너에 현재 탭만 파랑으로 채우는 방식으로 단순화. 과한 호버 효과(그림자·이동·광택 스윕) 제거

### 2. 패널 제목

- "시설물" 옆에 **조회 건수 pill**(2,474) 추가 — 무엇을 몇 건 보고 있는지 바로 보임
- 배경을 회색에서 흰색으로 바꿔 아래 검색 영역과 이어지게 함

### 3. 검색

- **시설물명·기관명 검색 입력** 추가(돋보기 아이콘, 지우기 버튼, ESC로 초기화)
- 서버를 다시 부르지 않고 이미 받은 목록을 걸러 다시 그림 — 행정구역 select만 서버 재조회
- 건수 표기 분리: 패널 제목 옆은 **조회 전체**, 검색 영역은 **현재 표시 중**

### 4. 목록 항목

- `아이콘 | 이름 + 소속 | 배지` 3단 구조로 재구성
- 아이콘은 **지도 핀과 같은 SVG**를 축소해 사용(종류·보수필요 색 규칙 공유)
- 소속 줄에 **기관명 · 지사/청사명** 표시 → "강당"이 반복돼도 구분됨
- 구분선 대신 카드형 hover/선택 스타일, 얇은 커스텀 스크롤바

## 남은 개선 후보

- 지도 우측 세로 툴바(측정·로드뷰·편의시설·교통·지도캡쳐)의 PNG 아이콘이 새 톤과 어울리지 않습니다. 같은 방식으로 SVG 정리 가능.
- 배경지도 전환(일반/위성) 카드도 투박한 편입니다.
- 커밋·push는 하지 않았습니다.
