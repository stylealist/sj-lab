## 작업 내용

v2.18에서 "묶음을 클릭하면 펼침"이었던 것을 **배율에 따라 저절로 펼쳐지도록** 바꿨습니다.

| 항목 | 파일 | 내용 |
|---|---|---|
| 동기화 진입점 | `js/modules/map/map-facility.js` | `syncFacilitySpiders()` 신설 — `moveend`(확대·이동 종료)마다, 필터 변경·목록 재조회·묶음 토글 때 호출. 펼친 구성이 그대로면(대상 id 목록 + 해상도로 만든 `facilitySpiderKey` 비교) **아무것도 다시 그리지 않음**(이동 시 깜빡임 방지) |
| 기준 배율 | 〃 | `FACILITY_SPIDER_MIN_ZOOM = 16` 이상에서 펼치고, 그 미만으로 축소하면 자동으로 접힘 |
| 대상 판정 | 〃 | `collectFacilitySpiderGroups()` — 묶어 보기 켬: 화면 안 묶음 중 구성원 extent 가 화면 1픽셀 미만인 것. 묶어 보기 끔: **좌표가 같아 완전히 겹치는 핀들**(필터 통과분만)도 같은 방식으로 펼침 |
| 클릭 동작 | 〃 | 묶음 배지 클릭은 **확대만** 함. 좌표가 같은 묶음이면 펼침 배율까지 올려 주고, 그 결과로 동기화가 펼침. 펼쳐진 핀 클릭은 종전대로 상세 팝업 |
| 문서 | `docs/map-architecture.md`, `docs/ui-conventions.md` | 클릭 기반 서술을 배율 기반으로 교체(진입점·판정·깜빡임 방지 규칙 포함) |

## 검증 (로컬, 헤드리스 Chrome + CDP)

같은 자리 묶음(3·3·2건)이 있는 지점으로 이동한 뒤 배율만 바꿔 관찰했습니다.

| 배율 | 펼친 핀 / 연결선 |
|---|---|
| 11.3 (이동 직후) | 0 / 0 |
| 14 | 0 / 0 |
| 15 | 0 / 0 |
| **16** | **3 / 3** (자동으로 펼쳐짐) |
| 17 | 3 / 3 |
| 13 (다시 축소) | 0 / 0 (자동으로 접힘) |

| 그 밖의 확인 | 결과 |
|---|---|
| 펼쳐진 핀 클릭 | 해당 시설물이 목록에서 선택됨(1건) |
| 화면 캡처 | 배지 주변으로 핀 3개가 점선 연결선과 함께 펼쳐진 모습 확인 |
| `node --check` | 통과 |
