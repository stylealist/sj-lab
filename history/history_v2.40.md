## 실행한 프롬프트

```
ui가 너무 투박해서 세련되게 변경해주고 팝업을 드래그앤드랍으로 이동 할 수 있도록 해줘
```

범위가 갈릴 수 있어 먼저 확인했고, **범례만** 다듬고 **범례 박스**를 드래그 대상으로 하기로 정했습니다(시설물 상세·WFS·WMS 팝업은 이미 헤더 드래그가 됩니다).

## 작업 내용

### 1. 모양 정리 (`css/components/map-legend.css`)

| 항목 | 전 | 후 |
|---|---|---|
| 모서리·그림자 | 10px, 단색 그림자 | **14px**, 두 겹 그림자(`0 1px 2px` + `0 8px 24px -8px`)로 떠 있는 느낌 |
| 머리글 | 글자만 | **레이어 아이콘 배지**(연파랑 둥근 사각형) + 제목 + 꺾쇠, 호버 시 옅은 파랑 |
| 아이콘 정렬 | 크기가 제각각(핀 24×32, 공공데이터 32×32)이라 줄이 안 맞음 | **24×24 아이콘 칸**에 담아 정렬, 항목 호버 강조 |
| 구분 | 점선 | 옅은 실선 + 섹션 제목을 작게(10.5px, 자간 0.06em, 회색) |
| 접기 | 즉시 사라짐 | **높이·투명도 애니메이션**(0.24s), 꺾쇠 회전. `prefers-reduced-motion`이면 끔 |
| 배경 | `blur(10px)` | `blur(14px)` + 흰색 92% |

### 2. 드래그로 이동 (`js/modules/map/map-legend.js`)

- 머리글(`#mapLegendToggle`)이 **접기 버튼이자 드래그 손잡이**입니다. 움직인 거리가 **4px 미만이면 접기/펼치기**, 그 이상이면 이동으로 봅니다(끌고 난 직후의 `click`은 `dataset.suppressToggle`로 한 번 무시).
- 옮긴 자리는 지도 컨테이너 기준 `{left, top}`으로 `localStorage`(`sjLabMapLegendPos`)에 저장하고 다음 접속에 복원합니다.
- `clampLegendPosition()`이 지도 폭과 **화면에 보이는 아래 끝**(컨테이너가 헤더 높이만큼 넘쳐 있어 `window.innerHeight` 기준)을 함께 봐서 가장자리 밖으로 나가지 못하게 막습니다. 창 크기가 바뀌거나 접었다 펴도 다시 맞춥니다.
- 옮긴 뒤에는 기본 자리(`left`/`bottom`) 대신 인라인 `left`/`top`(+`bottom: auto`)으로 붙고, `positionLegendAboveViewportBottom()`은 그 자리를 유지만 합니다.
- pointer 이벤트로 처리하고 머리글에 `touch-action: none`, `pointerdown` 전파 차단(지도가 같이 끌려가지 않도록). 끄는 동안에는 `is-dragging` 클래스로 그림자만 키웁니다(위치 계산에 영향이 없게 `transform`은 쓰지 않음).

## 검증 (로컬, 헤드리스 Chrome + CDP, 1440×1000)

실제 마우스 이벤트(`Input.dispatchMouseEvent`)로 끌어서 확인했습니다.

| 확인 | 결과 |
|---|---|
| 초기 위치 | `[348, 602] ~ [560, 984]` (왼쪽 아래 기본 자리), 저장값 없음 |
| 오른쪽 위로 420×320 끌기 | `[768, 282]`로 이동, `sjLabMapLegendPos = {"left":768,"top":222}` 저장, 접히지 않음 |
| 화면 밖으로 1200×900 끌기 | `[1220, 68] ~ [1432, 450]`에서 멈춤 — **화면 안에 그대로**(가장자리 여백 8px) |
| 제자리 클릭(움직임 없음) | 접힘 ✔ (드래그로 오인하지 않음) |
| 다시 펼치고 새로고침 | 옮긴 자리 `[1220, 68, 1432, 450]` 그대로 복원 |
| 콘솔 오류 | 없음 |
