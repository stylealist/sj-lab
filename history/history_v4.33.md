## 1. 관심 단지에 "목표가" 를 적을 수 있습니다 (새 기능)

담아 둔 단지마다 **"얼마가 되면 알려 줘"** 를 적어 두면, 그 뒤에 올라온 거래 중 조건에 맞는
것이 있을 때 화면이 알려 줍니다.

```
단지 상세 :  ★   🎯 목표가   ✎ 메모   ✕
                  └ 누르면 → [매매가|전세]  [ 15.5 ]억  [이하|이상]  평형 [34평]

닿으면    :  🔔 14.9억   ← 단지 상세 · 마이페이지 카드 · 지도 핀(빨간 점) · "내 단지" 단추
```

**메일이나 휴대폰 알림이 아닙니다.** 화면에 들어왔을 때 배지로 보여 줍니다 — 이미 쓰고 있는
"새 거래 N건" 과 같은 방식이라 따로 보낼 통로가 필요 없습니다.

### 신경 쓴 것 세 가지

| | 왜 |
|---|---|
| **평형을 함께 고릅니다** | 한 단지에 24평·34평이 같이 있어, 단지 전체에 "15억 이하" 를 걸면 **작은 평형 때문에 늘 도달**합니다 |
| **정한 뒤의 거래만 셉니다** | 그렇게 하지 않으면 과거에 그 값에 닿은 적 있는 단지는 **정하자마자 "도달"** 로 떠서 알림이 뜻을 잃습니다 |
| **지도 표시는 가벼운 길로** | 관심 목록 전체는 단지마다 거래를 세는 무거운 조회입니다. 목표가를 정한 단지만 보는 길을 따로 뒀습니다 — 하나도 안 정했으면 아예 돌지 않습니다 |

### 미리 확인한 것

스크립트를 돌리기 전에 **실제 DB에서 조회만으로 미리 검증**했습니다(가짜 행으로 흉내).
삼성래미안 32평 · 8.5억 이하 조건에서 `도달 39건 · 가장 최근 2026-05-09 · 8.5억` 이 나왔고,
**금액과 날짜가 같은 거래**를 가리키는 것까지 확인했습니다.

덤으로 관심 목록에 **최근 거래가**가 함께 옵니다 — 목표가와 나란히 봐야 "얼마나 남았나" 가
읽힙니다.

## 3. 오늘 함께 들어간 것들 (같은 날 작업)

| | 내용 |
|---|---|
| **마이페이지** | 관심 단지·메모·최근 본 단지를 한 화면에 펼쳐 봅니다. 메모를 여기서 바로 고칩니다 |
| **지도 위 "내 단지"** | 지도를 떠나지 않고 담아 둔 단지를 꺼내 보고, 고르면 지도가 그 자리로 갑니다 |
| **지도에서 내 단지가 보입니다** | 담은 단지는 **노란 말풍선**, 메모가 있으면 **하늘색**. 마우스를 올리면 메모가 쪽지로 뜹니다 |
| **배경지도 고르기** | 일반 · 위성(하이브리드) · 지형을 그림 단추로 고릅니다 |
| **단계 안내가 토스트로** | "읍면동 범위" 같은 안내가 고정 자리를 차지하지 않고 위에서 잠깐 떴다 사라집니다 |
| **관심·메모 저장 오류(403) 수정** | 로컬에서만 나던 문제로, 개발용 중계 설정을 고쳤습니다(운영은 영향 없음) |
| **기간 선택의 `~` 가 가운데로** | 오른쪽으로 쏠려 보이던 것을 바로잡았습니다 |
| **로고를 누르면 처음 화면으로** | 실거래 화면을 새로 엽니다 |
| **안 보이던 테두리 25곳 복구** | 전날 색을 한꺼번에 바꾸면서 테두리 값이 깨져 있었습니다 |
