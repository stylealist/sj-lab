## 작업 내용

### 1. 전체 설명 영상 (6분 10초)

화면녹화 4개를 업무 흐름 순서로 편집했습니다. 규격이 제각각(2544×988 · 2544×912 가로, **720×1760 세로 모바일**)이라 1920×1080 캔버스로 정규화하고, 남는 여백은 같은 화면을 확대·블러 처리해 채웠습니다.

| 시작 | 구간 |
|---|---|
| 00:00 | 인트로 카드 |
| 00:05 | ① QGIS → QFieldCloud (레이어 구성·업로드) |
| 01:14 | ② 현장조사 앱 (신규 시설물·현장 미디어) |
| 03:08 | ③ 웹 내업 처리 & 기능 (상세·내업 작성·PDF·레이어·측정·캡처) |
| 05:54 | ④ 소개 · 연락처 |
| 06:06 | 아웃트로 |

- 자막 **33개**를 ASS로 번인. 프레임을 직접 확인해 화면과 시점을 맞췄습니다(예: 내업 작성 폼이 뜨는 시점에 "처리 상태·담당·일정·비용과 처리 전/후 사진을 등록합니다").
- 구간 라벨을 좌측 상단에 상시 표시, 카드·구간 전환에 페이드 적용.

### 2. 개인정보 블러

현장조사 앱 구간에 **담당자명·전화번호·이메일**이 보이는 장면이 있어 가림 처리했습니다.

- 위치 특정: 0.5초 간격 필름스트립으로 노출 구간을 **100.0s~104.6s**(앱 영상 기준)로 좁힘
- 처리: 스케일 **전** 원본 좌표계(720×1760)에서 하단 패널 영역(`y 1040, 720×720`)에 `boxblur`, 해당 시간에만 `enable`
- 자막도 "담당 부서·담당자 정보까지 현장에서 확인 (개인정보는 가림 처리)"로 교체

### 3. 요약 영상 (1분 05초)

팝업용 요약본을 따로 만들었습니다 — 타이틀 카드 + 핵심 장면 6개(업로드 / 조사 입력 / 미디어 첨부 / 웹 확인 / 내업·PDF / 레이어·도구) + 아웃트로. **무음으로 인코딩**해 브라우저 자동재생 정책에 걸리지 않게 했습니다.
