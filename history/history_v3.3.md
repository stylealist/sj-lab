## 실행한 프롬프트

```
api센터의 허브로 버튼을 mapservice에 있는 (2×2 격자 아이콘 + "허브" 라벨의 hub-link)
허브 버튼으로 변경해줘
```

## 무엇이 문제였나

지도 서비스에는 헤더에 **격자 아이콘 + "허브"** 알약 모양 버튼이 있는데,
API 센터는 **"허브로"** 라는 글자만 있는 네모난 버튼이었습니다.
두 사이트를 오가면 같은 일을 하는 버튼이 서로 달라 보였습니다.

## 어떻게 바꿨나

지도 서비스의 버튼을 그대로 가져왔습니다.

| 항목 | 전 | 후 |
|---|---|---|
| 아이콘 | 없음 | 2×2 격자(허브를 뜻하는 모양) |
| 글자 | 허브로 | 허브 |
| 모양 | 모서리 살짝 둥근 네모 | 알약 모양 |
| 마우스를 올리면 | 변화 없음 | 살짝 밝아짐 |
| 마우스를 올렸을 때 설명 | 없음 | "sj-lab 허브로 이동" |

- 누르면 가는 곳은 그대로입니다 — 로컬은 3000번, 운영은 사이트 첫 화면.
- 헤더의 다른 부분(제목, 사용자 이름, 로그아웃)은 건드리지 않았습니다.

## 어떻게 확인했나

- **빌드 성공**(오류 없음)
- 빌드 결과에 격자 아이콘이 들어간 것 확인
- 옛 글자("허브로")가 더 이상 남아 있지 않은 것 확인

## 남은 이야기

- 지도 서비스는 화면이 좁아지면 글자를 숨기고 아이콘만 남깁니다. API 센터는 스타일을 넣는 방식이 달라
  (파일 하나에 자바스크립트로만) 그 처리는 넣지 못했습니다. 좁은 화면에서도 글자가 같이 보입니다.
