# history v2.24 — 로고 클릭이 "무반응"으로 보이던 문제(첫 화면으로 복귀 동작 추가)

- **영향 저장소**: `sj-lab-mapservice`(프론트), `mapservice-rest`(기록)
- **이전 버전**: [history_v2.23.md](history_v2.23.md)

## 실행한 프롬프트

```
로컬에서 클릭해보니까 아무런 반응이 없어
```

## 원인

v2.23에서 로고 클릭을 404 나던 절대 경로 이동 → **SPA 페이지 전환**으로 바꿨는데, **이미 지도 화면일 때는 전환할 것이 없어 화면이 그대로**였습니다. 404는 사라졌지만 사용자 입장에서는 "눌러도 아무 일도 안 일어남"이었습니다.

## 조치

| 항목 | 파일 | 내용 |
|---|---|---|
| 첫 화면 복귀 | `js/modules/map/map-core.js` | 기본 중심·배율을 상수로 분리(`DEFAULT_MAP_CENTER` `[127.0, 37.5]`, `DEFAULT_MAP_ZOOM` 10, 지도 생성 시에도 이 값 사용)하고 `resetMapView()` 신설 — 400ms 애니메이션으로 첫 화면 복귀. **레이어 표시·필터·선택 상태는 건드리지 않음** |
| 전역 등록 | `js/modules/map/map.js` | `window.resetMapView = resetMapView`(저장소 규칙: 모듈 밖에서 쓰는 함수는 `map.js`에서 `window`에 등록) |
| 로고 동작 | `js/modules/ui.js` | `goToMap()`이 지도 페이지로 전환한 뒤 `window.resetMapView()` 호출. 지도 탭 버튼이 없으면 종전처럼 `./` 폴백 |
| 문서 | `docs/ui-conventions.md` | 로고 클릭 규칙에 "전환 + 첫 화면 복귀"와 그 이유 추가 |
