## 실행한 프롬프트

```
클러스트 기능에 오류가 있는데 (스크린샷) 도로교통공단 제주교통방송 부분이 끝까지 확대해도 핀이 안나와
```

## 원인

v2.19~v2.20의 자동 펼침 조건이 **"구성원 좌표가 사실상 같을 때"**(extent 폭·높이 < 화면 1픽셀)로 좁았습니다.

- 제주교통방송 4건처럼 **몇 미터씩 떨어져 있는** 시설물은 이 조건에 걸리지 않습니다.
- 그런데 간격이 묶음 거리(`FACILITY_CLUSTER_DISTANCE` 44px)보다 좁으면 **최대 배율에서도 계속 묶입니다.**
- 결과: 펼쳐지지도 않고 풀리지도 않아 **지도에서 그 시설물들을 고를 수 없었습니다.**

## 조치

| 항목 | 파일 | 내용 |
|---|---|---|
| 펼침 조건 | `js/modules/map/map-facility.js` | 묶어 보기가 켜져 있으면 **화면 안에서 아직 묶여 있는 묶음 전부**(구성원 2개 이상)를 펼치도록 변경. "이 배율까지 확대했는데도 묶여 있다 = 더 확대해도 풀리지 않거나 풀려도 겹친다"는 판단 |
| 클릭 동작 | 〃 | 구성원이 화면에서 묶음 거리보다 좁게 붙어 있으면(`spreadPx < FACILITY_CLUSTER_DISTANCE`) `fit` 대신 `max(현재+2, 18)` 배율로 확대 — 예전 "좌표 동일" 판정 대신 픽셀 간격으로 판단하므로 같은 함정에 걸리지 않음 |
| 정리 | 〃 | 더 이상 쓰지 않는 `isSameSpotMembers()`와 불필요한 지역 변수 제거 |
| 문서 | `docs/map-architecture.md`, `docs/ui-conventions.md` | 새 조건과 **왜 좁은 조건이 실패했는지**(이번 사례) 기록 |
