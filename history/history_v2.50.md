## 무엇이 어긋나 있었나

| 카드 | 전(사진) | 문제 |
|---|---|---|
| 주기적으로 받아오기 | QGIS의 QFieldCloud 프로젝트 창 | **QGIS에서 올리는 장면** — 워커가 받아오는 이야기와 다름 |
| 지도에 내려주는 API | 지도에 핀이 찍힌 화면 | API가 아니라 **결과 화면**이고, 바로 아래 "핀 묶음" 사진과 거의 같음 |
| 웹에서 확인하고 처리 | 내업 작성 + 파일 탐색기 창 | 파일 선택 창이 화면 절반을 덮어 무엇을 하는지 알기 어려움 |

## 교체한 사진

| 카드 | 후(사진) |
|---|---|
| 주기적으로 받아오기 | **현장 앱이 QFieldCloud와 데이터를 주고받는 화면**("최신 데이터를 패키징 중입니다") |
| 지도에 내려주는 API | **API 목록 문서(Swagger)** — `GET /qfield/facilities`, 내업·보고서 엔드포인트가 보이는 화면 |
| 웹에서 확인하고 처리 | **상세 창에서 현장 영상을 보며 내업 내용을 적는 화면**(파일 창 없음) |

- "앱으로 현장 조사" 사진은 그대로 두었습니다(앱에서 시설물 정보를 입력하는 화면).
- 설명(alt) 문구도 바뀐 사진에 맞게 고쳤습니다.
- API 사진은 로컬에서 실제로 띄운 Swagger 화면(`localhost:8100/map/swagger-ui`)을 찍어 800×450으로 맞췄습니다.
