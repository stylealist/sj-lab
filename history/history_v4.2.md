## 실행한 프롬프트

```
로컬에서 접속할수있도록 해주고 허브에서도 접속 할 수 있게 해줘
부동산 실거래 누르면 부동산 실거래 페이지로 이동되지않는데?
```

## 1. 왜 안 열렸나

허브 카드는 제대로 동작했습니다. 누르면 부동산 페이지(4200)로 이동했지만, **그 페이지가
"로그인했는지" 확인하려고 로그인 화면으로 보내고, 로그인 화면이 다시 돌려보내 주지 않았습니다.**

로그인 화면에는 **되돌아가도 되는 주소 목록**이 있습니다(엉뚱한 사이트로 튕겨 보내는 공격을
막는 장치). 새로 만든 부동산 페이지 주소가 그 목록에 없어서, 로그인은 되는데 원래 자리로
돌아오지 못하고 로그인 화면에 머물렀습니다. **쓰는 사람 눈에는 "카드를 눌러도 아무 일이 없다"로
보입니다.**

같은 일이 2026-09-29 API 활용 페이지(4100)에서도 있었습니다. 그래서 이번에는 재발하지 않도록
**문서 네 곳에 "새 화면을 만들면 이 목록도 같이 고칠 것"을 적어 뒀습니다.**

## 2. 고친 내용

로그인 화면의 허용 목록에 부동산 페이지 주소를 넣고 로그인 서버를 다시 띄웠습니다.

```
허용 목록: 허브 3000 · 지도 4000 · API 활용 4100 · 부동산 4200 · sj-lab.co.kr
```

운영 주소(`sj-lab.co.kr/estate/`)는 이미 허용된 도메인 아래 경로라 따로 넣을 필요가 없습니다.

## 3. 확인

로컬에서 네 화면과 부동산 API를 모두 확인했습니다.

| 확인 | 결과 |
|---|---|
| 허브 3000 · 지도 4000 · API 활용 4100 · 부동산 4200 | 모두 정상(200) |
| 로그인 화면에 부동산 주소가 들어갔는지 | 들어감 |
| 부동산 API(매물 종류 조회) | 3종(아파트 서비스 / 오피스텔·빌라 준비 중) |
| 허브 카드 → 부동산 이동 | 정상 |

로그인 서버를 다시 띄운 뒤, 서비스 목록(Eureka)에 남아 있던 **죽은 옛 인스턴스를 직접
지웠습니다** — 그냥 두면 게이트웨이가 절반을 죽은 쪽으로 보내 로그인 화면이 간헐적으로
실패합니다(1~3분이면 저절로 사라지지만 기다리지 않았습니다).
