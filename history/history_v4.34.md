## 1. 목표가에 닿으면 **카카오톡**으로 알려 줍니다

사이트에 들어오지 않아도 알 수 있는 길이 생겼습니다.

```
[새 거래 수집] → [30분마다 감시] → 카카오톡 "나와의 채팅"
                                   🔔 목표가 도달
                                   삼성래미안 32평 (안양동)
                                   매매 8억 4,000만 거래 · 2026-11-20
                                   내 목표 8억 5,000만 이하
                                          [ 단지 보기 ]
```

### 왜 이 방식인가

흔히 받는 **알림톡**은 사업자등록증 · 비즈니스 채널 · 공식 딜러사 계약 · 템플릿 사전 심사가
필요하고 건당 비용도 듭니다. 반면 카카오톡 **"나에게 보내기"** 는 사용자가 자기 카카오로 한 번
동의하면 그 사람의 "나와의 채팅" 으로 보낼 수 있고 **등록·심사·비용이 없습니다.** 대신
**본인에게만** 가는데, "내가 담아 둔 단지 알림" 은 그걸로 충분합니다.

### 신경 쓴 것

| | |
|---|---|
| **보내기 전에 먼저 적는다** | 카카오톡은 **한 번 가면 취소할 수 없습니다.** 보낸 뒤에 적으면 서버가 여러 대일 때 같은 알림이 두 번 갑니다 |
| **토큰은 화면에 안 내려간다** | 브라우저로 한 번이라도 내려가면 그 순간부터 비밀이 아닙니다. 화면은 "연결됨/안 됨" 만 압니다 |
| **실패가 쌓이면 스스로 멈춘다** | 카카오 쪽에서 연결을 끊었는데 계속 두드리면 로그만 쌓입니다 |
| **세 겹으로 꺼진다** | 키가 없거나 · 표가 없거나 · 연결 안 했으면 조용히 꺼지고 화면 배지는 그대로 돕니다 |
| **로그인 화면을 건너뛰지 않는다** | 카카오는 세션이 남아 있으면 아무것도 묻지 않고 되돌려 보냅니다 — "저절로 연결됐다" 로 보이고 다른 계정으로 바꿀 수도 없어, 로그인을 다시 거치게 했습니다 |

### 설정에서 고생한 것 (다음을 위해 적어 둡니다)

| 오류 | 뜻 | 고친 곳 |
|---|---|---|
| `KOE006` | 등록 안 된 돌아올 주소 | 앱 → 플랫폼 키 → REST API 키 **상세 설정** → 카카오 로그인 리다이렉트 URI (**끝의 `/` 까지** 정확히) |
| `KOE010` | 자격증명 거부 | 카카오 로그인 → **고급** → Client Secret 이 켜져 있었습니다 |

**가짜 code 로 설정만 미리 검사할 수 있습니다** — 사용자가 카카오 로그인을 하지 않아도
맞는지 알 수 있어, 다음엔 한참 헤매지 않아도 됩니다.

```
code=NOT_A_REAL_CODE 로 토큰 요청
  KOE010 → 설정이 아직 틀렸다
  KOE320 → 통과 (진짜 code 면 성공)
```

오류 본문이 **두 가지 형식**이라(토큰은 `error_code`, 나머지 API 는 `code`) 한쪽을 못 읽어
로그에 `HTTP 401` 만 남았던 것도 함께 고쳤습니다.

## 2. 어디서든 고칠 수 있습니다

종전에는 **단지 상세에서만** 고칠 수 있었습니다. 모아 놓고 보는 화면에서 고치러 지도로
들어가야 한다면 모아 둔 보람이 없습니다.

| | 전 | 후 |
|---|---|---|
| 목표가 | 단지 상세만 | **단지 상세 · 마이페이지** 둘 다 |
| 메모 | 단지 상세 · 마이페이지 | 그대로 (**취소·저장** 단추 생김) |
| 관심 | ✕ 로 빼기 | **별(★/☆) 로 켜고 끄기** — 네 화면이 같은 기호 |

**입력칸은 복사하지 않고 한 파일로 모았습니다**(`TargetForm.js`). 같은 칸이 두 군데 있으면
금액 단위나 평형 식이 조용히 어긋납니다. 평형만 자리마다 다릅니다 — 단지 상세는 그 단지의
평형 목록을 알아 **고르는 상자**, 마이페이지는 모르니 **숫자 입력**입니다.

**쓰려는 자리에서 카카오를 연결합니다.** 연결 단추를 마이페이지에만 두었더니 **목표가를
정하는 사람이 그런 기능이 있는 줄도 몰랐습니다.** 이제 목표가 쪽지 안에서 바로 연결합니다.

## 3. 보시면서 바로 고친 것들

| 지적 | 고친 것 |
|---|---|
| 단지 이름이 `11650-3500` 으로 나온다 | **메모만 남기고 관심에 담지 않은 단지**였습니다. 이름을 함께 싣도록 고쳤고, 서버도 이름이 비면 **단지 표에서 채웁니다** |
| 관심을 해제하면 메모·목표가도 같이 지워지는 게 맞다 | 그렇게 바꾸고, **지우기 전에 무엇이 사라지는지 먼저 묻습니다**(담아 둔 게 없으면 바로 제거) |
| ✕ 를 누르면 목표가가 바로 사라진다 | 한 번 더 묻습니다 |
| "고치기" 단추가 이상한 곳에 있다 | **줄 전체**를 누르면 고쳐집니다 |
| 취소·저장이 붙어 있다 | 사이를 띄웠습니다 |
| 카카오 줄이 안 보인다 | 입력칸을 옮기면서 **상태를 묻는 코드를 함께 지웠던 것**입니다 |
| 목표가 도달 숫자가 `-` 로 나온다 | 숫자만 받던 칸에 `"0 / 1"` 이라는 **글**을 넣어 생긴 일입니다(두 화면에서 같은 함정) |

**담기가 가끔 502 로 실패하던 것도 찾았습니다.** 회원 질의 제한이 5초인데, 담기 문장 안에
실거래를 뒤지는 조회가 두 개 들어 있어(담는 순간의 최근 계약일을 적느라) 그 시군구를 처음
건드리면 넘겼습니다 — **실측 5.8초**. 15초로 올렸고, 더 나은 해법도 코드에 적어 두었습니다.
