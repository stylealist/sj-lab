# 부동산 지도(호갱노노 형태)로 가는 길

> 2026-10-13 조사. 숫자는 모두 **운영 DB(`sjlab`)에서 직접 확인한 값**입니다.
> 결론: **핀 지도는 지금 데이터로 불가능**하고(좌표가 없음), **좌표를 얻는 방법은 정해져 있습니다.**
> 좌표 없이도 되는 지도(읍면동 색칠)는 **추가 데이터 0건으로 지금 가능**합니다.

## 1. 지금 가진 것 / 없는 것

| | 상태 |
|---|---|
| 거래 데이터 | 매매 984만 · 전월세 1,099만 건 (2006-01~) |
| 주소 | 지번·도로명 **코드까지** 있음 |
| **좌표(위경도)** | **없음** — 원천(국토교통부 실거래 공개 API)이 주지 않음 |
| 행정구역 경계 | **있음** — `public.g_sido`(17) · `g_sgg`(252) · `g_emd`(5,061) |

**좌표가 필요한 단지 수: 44,581개**

| 구분 | 단지 수 |
|---|---|
| 매매에 있는 단지(`apt_seq`) | 41,512 |
| 전월세에 있는 단지 | 43,279 |
| └ 그중 매매에도 있음 | 40,210 (93%) |
| └ 전월세에만 있음 | 3,069 |
| **합계(좌표를 구해야 하는 단지)** | **44,581** |

거래는 2,100만 건이지만 **단지는 4.5만 개**입니다. 단지마다 좌표를 한 번만 구하면
`apt_seq`로 모든 거래에 붙습니다 — 이게 이 작업이 현실적인 이유입니다.

## 2. 두 표의 키로 좌표를 얻는 방법 (핵심)

### 방법 A — 행안부 도로명주소 **좌표제공 API** (1순위)

주소 문자열을 맞춰 보내는 방식이 아니라, **우리가 가진 코드를 그대로 조립**해 보냅니다.
오타·별칭 때문에 깨지는 문자열 매칭이 필요 없습니다.

| API 파라미터 | 우리 컬럼 | 확인된 형식 |
|---|---|---|
| `admCd` (법정동코드 10자리) | `sgg_cd` + `umd_cd` | 10자리 (예: `2711015500`) |
| `rnMgtSn` (도로명코드 12자리) | `road_nm_sgg_cd` + `road_nm_cd` | 5 + 7 = 12자리 |
| `udrtYn` (지하 여부) | `road_nmb_cd` | `0`/`1` |
| `buldMnnm` (건물 본번) | `road_nm_bonbun` | 5자리 → 앞 0 제거 |
| `buldSlno` (건물 부번) | `road_nm_bubun` | 5자리 → 앞 0 제거 |

보유율(2026-09 표본 21,974건 기준): **도로명 키 99.7%**, 지번 키 100%.

```
예) 서울 강남구 대치동 "달성로 123"
    admCd=2711015500  rnMgtSn=271103141004  udrtYn=0  buldMnnm=123  buldSlno=0
```

- 응답 좌표계는 **EPSG:5179**(GRS80 UTM-K)입니다 → `ST_Transform(…, 3857)` 로 지도용으로 바꿉니다.
- **전월세 표에는 `umd_cd` 가 없습니다.** 그래서 `admCd` 를 못 만듭니다 — 다만 전월세 단지의 93%는
  매매에도 있어 매매 기준으로 구한 좌표를 `apt_seq` 로 붙이면 됩니다.
  전월세 전용 단지(3,069개)는 `sgg_cd + umd_nm` 으로 `public.g_emd` 에서 법정동코드를 찾을 수
  있는 비율이 **75%(905/1,212 동 조합)** 이고, 나머지는 아래 방법 B로 넘깁니다.

### 방법 B — VWorld 지오코더 (보조·2순위)

지번/도로명 **문자열**로 좌표를 받습니다. 방법 A로 못 구한 건을 메웁니다.

| 쓰는 값 | 우리 컬럼 |
|---|---|
| 지번 주소 | 시군구명(`g_sgg`) + `umd_nm` + `jibun` (예: `서울특별시 강남구 대치동 974`) |
| 산 여부 | `land_cd` |

- 지번은 매매·전월세 **양쪽에 100%** 있습니다 → 전월세 전용 단지도 이 길로 해결됩니다.

### 방법 C — 국토교통부 공동주택 기본정보(K-apt) (보조·부가정보)

**좌표는 주지 않습니다.** 대신 호갱노노식 단지 카드에 쓰는 정보를 줍니다 —
세대수 · 동수 · 준공일 · 주차 · 난방. 단지명+주소로 맞춰 붙여야 하므로 좌표 확보 뒤에 합니다.

### 쓰지 않는 쪽 — 카카오/네이버 지오코딩

한도는 크지만 **좌표를 저장하거나 다른 지도에 표시하는 것에 약관 제약**이 있습니다.
공공 API(A·B)로 충분하므로 쓰지 않습니다.

## 3. 좌표 없이 지금 할 수 있는 지도 (추가 데이터 0건)

**읍면동·시군구 단계구분도**(색칠 지도)는 지금 바로 가능합니다.

- 실거래의 `sgg_cd || umd_cd` 앞 8자리가 `public.g_emd.emd_cd` 와 **2,154개 중 2,141개(99.4%) 일치**
  (2026-09 표본 기준, 확인 완료).
- 지도 사이트(`sj-lab-mapservice`)의 레이어 패턴(`map.v_*_geojson` 뷰 → bbox API → OpenLayers)을
  그대로 쓰면 됩니다.
- 할 수 있는 것: 지역별 평균가·거래량 색칠, 클릭하면 그 지역 추세, 축소하면 시군구 단위.
- 호갱노노도 축소하면 이 형태로 보여 줍니다. **핀 지도의 선행 단계로 쓸 수 있습니다.**

## 4. 핀 지도까지의 순서

| 단계 | 할 일 | 비고 |
|---|---|---|
| 0 | **읍면동 색칠 지도** | 추가 데이터 0건, 지금 가능 |
| 1 | 키 발급 — 행안부 좌표제공 + VWorld | 사람이 신청(무료). 한도는 계정 등급별 |
| 2 | `estate.apt_complex` 표 생성 | `apt_seq` PK + 주소 조각 + `geom`(3857) + 출처·정확도·확인일 (DDL은 담당자) |
| 3 | 좌표 채우기 배치 | A → 실패분 B → 남은 건 단지명 검색. 4.5만 건, 하루 1만 한도면 4~5일 |
| 4 | `estate.v_apt_complex_geojson` + bbox API | 지도 백엔드와 같은 패턴 |
| 5 | 지도 화면 | OpenLayers 클러스터·스파이더링 코드 재사용. 핀 라벨 = 단지별 최근 실거래가(지금 데이터로 가능) |
| 6 | 단지 부가정보(K-apt) | 세대수·준공연도 → 핀 크기·필터·단지 카드 |

### 좌표 채우기 배치에서 미리 조심할 것

과거 데이터를 대량으로 받을 때 겪은 함정이 그대로 적용됩니다
(`docs/backfill-workflow.md` 참고) — 특히:

- **타임아웃을 반드시 걸 것**(없으면 한 건에 40분 멈춤)
- **429(한도 초과)를 빈 결과로 넘기지 말 것** — 조용히 빠진 구간이 생긴다
  (실제로 광주·전남 실거래가 그렇게 비었다)
- 실패한 단지는 다시 시도할 수 있게 **상태를 표에 남길 것**(`geocode_status`)
- 키·한도는 **계정별·엔드포인트별로 따로**다

## 5. 정리

| 질문 | 답 |
|---|---|
| 지금 호갱노노처럼 핀 지도가 되나? | **안 됩니다** — 원천에 좌표가 없습니다 |
| 무엇을 받으면 되나? | **행안부 도로명주소 좌표제공 API**(1순위, 우리 코드를 그대로 조립) + **VWorld 지오코더**(보조) |
| 몇 건 받아야 하나? | 거래 2,100만 건이 아니라 **단지 44,581개** |
| 지금 당장 되는 지도는? | **읍면동 색칠 지도** (경계·코드 매칭 99.4% 확인) |
| 부가정보(세대수·준공)는? | K-apt 공동주택 기본정보 — 좌표는 없고 단지 카드용 |
